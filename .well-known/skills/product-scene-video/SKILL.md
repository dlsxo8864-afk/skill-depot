# 상품 장면 이미지 → 영상

기존 8296 워크플로와 프로젝트를 유지한다. 제품 사진과 장면 이미지를 실제 영상 모델에 전달해 생성하고, 원본·무음 마스터·자막과 음성을 넣은 최종본을 구분한다. 사진 확대·팬, 모의 결과, 파일 다운로드만을 생성 품질 통과로 표시하지 않는다.

## 제품과 장면 기준

- 승인 제품 이미지·옵션·승인 버전·SHA256을 고정한다. 전처리 전 이미지와 실제 전송 바이트의 해시, 이미지 역할과 순서도 남긴다. 파일이 승인 해시와 다르면 제출 전에 멈춘다.
- 장면 이미지는 같은 정본에서 각각 파생한다. 앞 장면의 AI 결과를 연쇄 편집해 제품 외형·색상·구성품을 바꾸지 않는다. 실제 모델에 보낸 참조와 QC 대조용 정본을 구분한다.
- 유닛마다 핵심 행동 하나, 시작 자세와 마무리 자세, 카메라·공간 기하·이동 방향·소품 수량을 정한다. 접기·펴기처럼 구조가 크게 변하는 장면은 사진과 실제 제품 기능이 뒷받침하는지 먼저 확인한다. 장소나 구도가 복잡하면 유닛을 나누되 모든 영상을 일률적으로 나누지는 않는다.
- 이미 확인된 제품 특성과 사용자 대본을 따른다. 외형 보존을 위해 행동을 단순화했으면 해당 행동을 주장하는 내레이션도 맞춘다. 실제 측정 도구를 무지 리본으로 바꿔 측정 시연처럼 보이게 하지 않는다.
- 사진·영상에는 새 자막·배지·CTA를 생성하지 않는다. 글자는 후반 네이티브 레이어에서 조합한다. 직장 썰 전용 제목·발화자막·30초 규칙을 상품 광고에 강제하지 않는다.

## 구현과 실행

- 실행 중인 8296 프로세스·현재 소스·프런트엔드 경로를 먼저 대조한다. 다른 앱으로 갈아타지 않는다. 재시작 전 실행 중 작업이 0개인지 확인한다.
- 현재 제공자와 인증 연결을 우선한다. 최신 공식 스키마와 실제 오류를 확인하고 엔드포인트별 어댑터를 쓴다. Kling3는 start_image_url, Kling2.5는 image_url이다. Seedance R2V의 image_urls/aspect_ratio 계약을 I2V에 복사하지 않는다.
- 2026-11-04 실제 Kling3 결과 조회에서 prompt 최대 2500자 초과 422가 확인됐다. 장면 메타데이터 전체를 모델 프롬프트에 직렬화하지 말고, 행동·타이밍·정체성 보호 문장을 한도 안에 조립한다. 원래 장면 계획은 별도 증빙으로 보존한다.
- 반환된 request_id/status_url/response_url을 저장한다. 전체 엔드포인트 뒤에 임의 requests URL을 붙이지 않는다. POST 결과가 불명확하면 중복 제출하지 않는다. COMPLETED 뒤에도 결과 조회가 422 등으로 실패할 수 있다. 확정 입력 거절과 결과 유실을 구분한다.
- 제출·대기열·생성·다운로드·미디어 검사·제품 검사·등록 단계를 화면과 기록에 남긴다. 파일은 실제 probe가 가능한지 확인한다. 비용은 제공자 확정값·추정값·청구 미확인을 구분한다.
- 유료 실행 권한은 현재 사용자 요청을 따른다. 오래된 문서의 별도 승인 메모로 이미 승인된 실행을 다시 막지 않는다. 인증·한도·제공자 접근 오류를 우회하거나 다른 유료 계정으로 자동 전환하지 않는다.

## 검수와 편집

- 생성 성공, 기술 검사, 제품 동일성 검사, 사람의 선택은 각각 기록한다. 사람이 선택했다는 이유로 shape_ok:false를 검사 통과로 바꾸지 않는다. 해당 컷은 새 채택·출력에서 막고 원본 후보와 과거 납품 파일은 보존한다.
- 실제 MP4의 시작·중간·끝과 연결 경계를 재생해 제품 형태·색상·구성·손·소품·동작·글자·깨짐·멈춤을 확인한다. 자동 motion 점수만으로 정지 이미지 팬 여부를 단정하지 않는다.
- 영상 길이/fps/비율/오디오를 실측하고 나레이션 구간에 맞춰 편집한다. 마지막 유효 동작을 잘라 버리지 않도록 생성 여유와 소스 인·아웃을 구분한다. 전환은 같은 공간과 방향을 유지하고 실제 컷 경계를 보고 정한다.
- EP1 동봉 보고서와 QC 그리드는 실제 MP4와 불일치했다. 문서보다 파일·해시·요청 로그를 우선한다. EP2의 26프레임 제외와 직전 반응 컷 시간 조정은 해당 결함만의 편집 사례이며 새 영상에 같은 프레임을 복사하지 않는다.
