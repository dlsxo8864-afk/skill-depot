# 라이선스 정리 — llmvid-blender-clay-office

확인한 날: 2026-11-10. 조건은 바뀔 수 있으니 게시·판매 전에 각 출처를 다시 본다.

## 1. 팩에 든 것

| 파일 | 내용 | 출처 |
|---|---|---|
| `SKILL.md`, `LICENSES.md` | 절차와 설명 | 이 팩을 만들면서 직접 썼다 |
| `example/*.py`, `example/script.json` | 공통 예제 대본 「점심 메뉴 정하는 법」을 만든 스크립트와 타임라인 예제 | 이 프로젝트에서 LLM으로 작성했다. `create_office.py`는 Google CLI로 만든 기초 구현을 검토해 적용했고, `refinements.py`와 나머지 파일은 마감 코드다 |

- 팩 스크립트에 따로 라이선스를 붙이지 않았다. 받은 사람이 자기 영상을 만드는 데 고쳐 쓰라는 용도다.
- `create_office.py`, `refinements.py`, `preview_checks.py`, `render_final.py`는 블렌더 내부 파이썬 API(`bpy`)를 사용한다. 블렌더 재단은 "`bpy`를 사용하는 스크립트를 외부에 공개 배포할 때는 GNU GPL 호환 라이선스를 따라야 한다"고 공식 안내하고 있다(https://www.blender.org/about/license/ 의 Add-ons 항목). 이 팩의 스크립트를 외부에 재배포하려는 경우 해당 조건을 확인해야 한다.
- 팩에 포함되지 않은 항목: 내레이션 음성 파일, 배경 음악 파일, 최종 렌더된 프레임 이미지, `.blend` 바이너리 파일, 외부 3D 에셋, 글꼴 파일.

## 2. 팩이 쓰는 도구

| 도구 | 라이선스 | 결과물에 미치는 영향 |
|---|---|---|
| Blender 4.5.15 LTS / 5.2.3 | GNU GPL (v3 이상으로 배포) | 블렌더로 만든 그림·영상·`.blend` 파일은 만든 사람의 것이다(블렌더 라이선스 페이지의 Your Artwork 항목) |
| ffmpeg | 빌드 구성에 따라 LGPL 또는 GPL | 생성 및 인코딩된 동영상 파일의 저작권에는 영향을 주지 않는다. ffmpeg 실행 바이너리 자체를 제품에 포함해 재배포할 때만 라이선스 의무가 발생한다 |
| Python 3.10+ | PSF License | 결과물에 대한 제약 없음 |
| Pillow | MIT-CMU (HPND) | 결과물에 대한 제약 없음 (`sheet.py` 시트 생성 시에만 사용) |

H.264(libx264)·AAC로 인코딩한다. 일반적인 영상 게시에는 문제가 되지 않지만, 인코더를 제품에 넣어 파는 경우는 특허 라이선스를 따로 확인한다.

## 3. 외부 소재

외부 소재 없음, 전부 코드로 만든 도형.

- 외부 3D 모델(gltf, fbx, obj 등), 외부 텍스처 이미지(diffuse, roughness, normal 등), HDRI 환경 맵, 외부 2D 일러스트를 전혀 사용하지 않는다.
- 사무실 미니어처 세트, 책상, 의자, 프린터 기기, 출력물 종이, 창문, 화분 및 등장인물 3명의 얼굴, 몸통, 팔다리, 머리카락, 안경 등 모든 구성 요소는 블렌더 내장 파이썬 코드를 통해 기본 도형을 배치하고 절차적 재질을 부여해 생성된다.

## 4. 글꼴

- 팩 자체에는 폰트 파일이 포함되어 있지 않다.
- `fontfind.py` 스크립트가 사용자의 운영체제에 설치된 글꼴을 순서대로 탐색한다: Noto Sans KR → 맑은 고딕 순으로 감지한다.
- **Noto Sans KR:** SIL Open Font License 1.1.
- **맑은 고딕:** Windows에 딸린 글꼴이다. Windows 글꼴 라이선스를 따른다. 조건이 분명해야 하는 게시·상업용이면 Noto Sans KR을 설치해 쓰거나 `--font`로 권리가 분명한 글꼴을 넘긴다.
- `finish.py`는 자막 렌더링 과정에서 탐색된 시스템 글꼴 파일을 작업 디렉터리 내 `fonts/` 폴더로 복사한다. 이 복사된 폰트 파일은 작업용 중간 산출물이므로 제3자에게 임의로 재배포하거나 공유하지 않는다.

## 5. 음성·효과음

- 내레이션 음성 파일과 배경 음악 파일은 팩에 동봉되어 있지 않다.
- 음성 파일은 사용자가 직접 녹음하거나 TTS(음성 합성) 서비스를 통해 생성하여 준비해야 한다. TTS 음성을 사용할 경우 해당 서비스의 상업적 이용 허용 범위 및 출처 표기 의무를 사용자가 직접 확인해야 한다.
- `--music` 인자로 전달하는 배경음 음원 역시 저작권과 사용 권리를 사용자가 직접 점검해야 한다.

## 6. 대본

예제에 포함된 대본(「점심 메뉴 정하는 법」)과 자막 문구는 동작 테스트를 위해 작성된 예시 자료다. 실제 영상을 제작할 때는 사용자가 작성한 고유 대본을 적용해 사용한다.
