## 오디오
- 마스터에 **오디오 스트림 자체가 없음** (ffprobe 스트림 0개).
- 원본 유닛에는 빈 트랙 대신 저레벨 잔음이 남아 있었음 (B −37.1dB / C −40.7dB / D −39.6dB / A −44.2dB). 전부 믹스 단계에서 제거.
- B·D 오디오를 STT로 전사한 결과 **인식된 발화 0건** — 지시대로 대사가 없는 무음 영상임을 확인.

## 자막
- **자막 원문 없음.** 이 프로젝트에 SRT/ASS 파일, 확정 대본, 나레이션 원문이 존재하지 않음(전체 경로 grep 결과 0건).
- 따라서 자막 MP4/SRT를 만들지 않았고, 대사를 임의로 창작하지도 않았음.
- 외부 여성 나레이션 트랙과 그 대본이 들어오면, 이 마스터의 컷 타임(4 / 12 / 20초)에 맞춰 자막을 얹은 별도 MP4와 SRT를 만들 수 있음. 안전영역은 얼굴을 피해 하단 20~28% 밴드, 최대 2줄.

## 재현 방법
```sh
# 유닛 정규화 (1080x1920 / 24fps / 무음)
ffmpeg -i unit_X.mp4 -t <길이> -vf "scale=1080:1920:flags=lanczos,fps=24,setsar=1" \
  -c:v libx264 -preset fast -crf 17 -pix_fmt yuv420p -an out.mp4
# 결합
ffmpeg -f concat -safe 0 -i list.txt -c copy -movflags +faststart master.mp4
```
