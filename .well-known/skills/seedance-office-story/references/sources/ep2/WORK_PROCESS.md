# 작업 과정 — 한국 직장 썰 30초 실사 단편

기록 시점의 최종 상태와, 거기까지 어떤 순서로 결정했는지를 남긴다. 실패한 선택도 이유와 함께 적었다 — 같은 상황에서 다시 그 길로 들어가지 않기 위해서다.

---

## 0. 입력

사용자가 준 것: 세로 9:16 / 30초 / 외부 여성 나레이션용 **무음** 영상 / 등장인물 대사 없음 / 화면 내 텍스트 전면 금지 / 인물 외형·복장 2벌 / 8개 비트의 타임코드 대본 / 장르 킬 라인(로맨스·추격·신체 접촉·연애 발전 없음).

프로젝트는 빈 상태였다. 보드도 에셋도 없음.

## 1. 방향 판단

- 대본의 0–3.6초(엘리베이터 CU)와 12.2–19.6초(월요일 엘리베이터)는 **같은 장소·같은 사건**이다. 그래서 구조를 "열리면서 확대 → 회상 → 같은 장면 복귀"로 잡았다. 엘리베이터가 감정의 팰린드롬이 되고, 마지막 30초 CU는 1컷 표정의 반전이 된다.
- 회상은 블러·빈티지 필터·비네트로 구분하지 않기로 했다. 와인바의 텅스텐 조명만으로 구분한다. "단정한 하드 컷" 지시를 지키는 쪽이 더 아프게 읽힌다.
- 남자는 와인바에서 말하지 않는다. 휴대전화를 들어 보이는 행동만. 두 번째에도 **더 가까이 가지 않는다** — 가까워지는 순간 같은 몸짓의 반복이 접근이 되어버리고, 이 썰의 웃음은 반복 자체에 있다.
- 사원증은 무지 흰 카드로 고정. 글자가 없는 물체를 요구해야 영상 모델이 글자를 지어내지 않는다.

## 2. 캐논 제작 (1차)

`character_sheet` / `scene_sheet` 계열 스킬을 붙여 여성 시트·남성 시트·엘리베이터·와인바·로비 플레이트를 생성했다.

**여기서 두 가지가 드러났다.**

1. 여성 시트가 "흰 막 낀" 톤으로 나왔다. 대비가 눌리고 피부가 반투명하게 떴다.
2. 와인바·로비 플레이트에 실제 글자가 박혀 있었다. 로비 카운터 위 "PICK UP 1/2" 간판, 와인바 병 라벨 전부.

**교훈**: 부정어("글자 없음")는 참조 이미지가 공급하는 픽셀을 지우지 못한다. 플레이트에 금지 요소가 있으면 **이미지 편집 단계에서 먼저 제거**하고, 제거된 결과를 다시 눈으로 확인한 뒤에 바인딩해야 한다.

→ `canon_lobby_v2.jpg`(간판 삭제), `canon_winebar_v2.jpg`(라벨 무지화)를 만들어 교체.

## 3. 여성 얼굴 재제작 (2차, 사용자 지시)

사용자 요구: 얼굴만 한국 드라마 주연급으로 세련되게. 남성 시트는 손대지 않음. 표정·각도·두 벌 의상 전부에 동일 적용. **덧칠·보정 금지, 처음부터 재제작.**

1차 시도(시트 전체를 한 번에 편집)는 **실패**했다. 모델이 각 얼굴을 작은 국소 수정으로 처리해서 변화가 거의 없었다.

2차 시도도 부족했다. 이목구비별로 "결정적으로 바꿀 항목"을 수치감 있게 지정해야 했다 — 눈 크기·턱선 각도·콧대·입술·중안면 비율을 항목으로 분리해서.

## 4. 캐논 재제작 (3차, 사용자 지시로 방식 전환)

사용자가 제작 방식을 명시적으로 바꿔 지시했다:

1. 정면 무표정 고해상도 1장을 먼저 만들고 **공통 기준 이미지**로 확정
2. 모든 표정·전신 컷을 기준 이미지에서 **각각 독립 생성**
3. 연쇄 재생성 금지 (1→2→3 금지)
4. 완성된 시트를 다시 생성 모델에 넣어 재묘사 금지
5. 시트는 **일반 이미지 편집 도구로 조립**, 라벨은 이미지 밖 여백에만

이 방식이 확실히 우수했다. 결과: `deliverables/canon_v4/` — 개별 PNG 12장 + 시트 4장.

검수 수치로 확인한 것:
- 배경 평균 RGB 130/130/133 (따뜻한 중간 밝기 웜그레이), 컷 간 편차 ±3
- 머리카락 명도 69/60/59 — 회색 부상 없음
- 하늘색 셔츠 196/208/239 — 흰색과 분리 유지
- 표정 2·3번 100% 확대: 팔자선·눈밑 처짐·이마 가로주름·턱 길어짐 전부 없음

## 5. 렌더 구조 — 단일 30초를 포기한 이유

5개 감수 패스(프롬프트 결함 / 장면 구성 / 인과 서술 / 레퍼런스 바인딩 / 구조)를 병렬로 돌렸다. 세 패스가 독립적으로 같은 결론에 도달했다:

> 장소 3곳 + 복장 2벌 + 13블록을 한 호출에 넣으면 모델이 세계를 평균화하고, 1초 블록 3개는 과밀이다.

→ **4유닛 분할**로 전환. 유닛당 레퍼런스 3~4장, 유닛당 한 세계.

| 유닛 | 구간 | 길이 | 장소 |
|---|---|---|---|
| A | 0–4s | 4s | 엘리베이터 (원테이크) |
| B | 4–12s | 8s | 와인바 (4블록) |
| C | 12–20s | 8s | 엘리베이터 (3블록) |
| D | 20–30s | 10s | 1층 로비 (4블록) |

## 6. 기하 오류 — 가장 비싼 실수 유형

감수에서 잡힌 것 중 실제로 화면을 망쳤을 것들:

- **엘리베이터 기하가 세 파일에서 서로 뒤집혀 있었다.** 카메라가 그녀 얼굴을 보는데 문이 그녀 머리 뒤에 있을 수 없다. 거울·손잡이도 플레이트 기준으로는 두 사람의 오른쪽 벽. → 카메라가 문 쪽 끝에서 안쪽을 보는 한 가지 기하로 통일하고, 문은 프레임 밖에 두어 렌즈가 거울에 비치지 않게 했다.
- **50mm로는 1.6m 폭 엘리베이터 안에서 두 사람 전신이 물리적으로 불가능.** 계산으로 확인됨. → 넓은 두 컷만 24mm를 블록에 명시.
- **와인바 카운터 방향이 플레이트와 반대**로 쓰여 있었다. → 그녀를 카운터 등지고 앉히고, 남자는 카운터 끝 왼쪽 진입. 좌우를 절대값으로 쓰지 않고 "그녀의 오른쪽 어깨 옆" 식 관계형으로 통일.
- **로비에서 걷는 방향이 두 컷에서 모순.** → 그녀가 향하는 곳(유리문)을 고정하고, 5–6초 분리는 좌우가 아니라 깊이로 처리.
- **엔딩 클로즈업이 "사라질 미소"를 요구하는데 그 미소를 먼저 만들지 않았다.** → 첫 프레임에 미소를 깔고 그것이 꺼지게.
- **턱을 드는 동작이 도전으로 읽힌다.** → 머리를 살짝 기울여 체념으로.

## 7. 모델이 못 그리는 것 — 프롬프트에서 제거

- "동공이 움직인다" → 측정 불가 항목. **눈꺼풀이 살짝 벌어지고 시선이 고정되는** 사건으로 교체.
- "억지 미소" → 명사 '미소'가 들어가면 활짝 웃는 쪽으로 과장됨. **입꼬리가 2mm 올라가 멈춘다**로, 웃음이라는 단어 없이.
- "숨이 멎는다" → 부재는 촬영 불가. **가슴이 움직이지 않는다**로 명시.
- "허탈한 표정" 같은 형용사 전부 폐기. 눈꺼풀·입꼬리·턱·목의 상태로만.

## 8. 렌더 결과 검수

네 유닛 완료 후 각각 프레임 그리드를 뽑아 대조했다.

- A: 원테이크 유지. 남자 어깨만 프레임 왼쪽에 걸리고 얼굴은 끝까지 미진입. ✓
- B: 하드컷 3회 (1.71 / 3.88 / 5.83s). 와인바 톤 유지, 회상이 회사 복장으로 새지 않음. ✓
- C: 하드컷 2회 (2.58 / 5.17s). 사원증 두 장 같은 높이, 거울에 얼굴 미반사. ✓
- D: 하드컷 3회 (1.75 / 4.38 / 6.29s). 마지막 CU에서 미소가 실제로 꺼짐. ✓

**모두 첫 렌더에서 통과.** 프롬프트 단계에서 잡은 것이 렌더 재작업을 없앴다.

## 9. 무음 처리

원본 유닛에 아주 작은 잔음이 남아 있었다 — A −44.2dB, B −37.1dB, C −40.7dB, D −39.6dB. 프롬프트에 "no sound at all"을 넣었는데도 남는다.

→ 납품 시 **오디오 스트림 자체를 제거**했다(ffprobe 스트림 0개 확인). B·D 오디오를 STT로 전사해 발화 0건도 확인. 그림은 멀쩡하니 재렌더하지 않는다.

## 10. 결합

- 유닛별로 1080×1920 / 24fps / setsar=1로 정규화 후 재인코딩 (crf 17)
- concat으로 결합, `-movflags +faststart`
- 결과: 720프레임 = **30.000초**, 오디오 스트림 0개
- 같은 타임라인을 **컴포저 노드**로 보드에 남겨 사용자가 직접 트림·재배열 가능하게

## 11. 자막

프로젝트 전체에 SRT/ASS·확정 대본·나레이션 원문이 없었다(전체 grep 0건). 지시대로 대사를 창작하지 않고 무음 합본만 완성한 뒤, 원문 부재를 `DELIVERY_NOTES.md`에 명시했다.

## 다시 한다면

1. 캐논은 **기준 컷 1장 → 개별 독립 생성 → 편집 도구 조립**. 시트를 통째로 재생성하지 않는다.
2. 플레이트의 금지 요소는 **이미지 단계에서 먼저 제거**하고 눈으로 확인한다.
3. 감수는 프롬프트 단계에서 병렬로 돌린다. 렌더 후 재작업보다 압도적으로 싸다.
4. 좌우를 절대값으로 쓰지 않는다. 관계형으로.
5. 무음은 프롬프트가 아니라 **믹스 단계에서** 보장한다.
