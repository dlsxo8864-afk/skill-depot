## 4. 감독 결정 사항

### 핵심 아이디어
> **"고백이 도착한 순간, 그는 이미 다른 방향으로 결말을 맞아두었다 — 그가 침묵하는 이유를 그녀만 모른다."**

### 관객 시계 (audience clock)
관객은 B보다 먼저 A의 결정을 안다(플래시포워드 + 서류철). 단 **결정의 내용은 끝까지 감춤** — 관객은 "그가 아는 것"과 "그녀가 모르는 것" 사이에서 긴장한다.

### 카메라 파라미터 (단일 축)
인물이 프레임에서 차지하는 스케일을 **조였다가 마지막에 단 한 번만 풀어준다.** 이 한 번의 이완이 30초 전체의 유일한 호흡 브레이크다.

### 시간대 압축 결정
원고의 5개 시간대를 30초에 모두 넣으면 각 장면이 정보 전달만 하게 되고, 심리 드라마에서 가장 비싼 것(침묵의 길이)을 잃는다.
→ **회의실 장면(00:04–00:09)을 "멈춘 손" 인서트로 압축.** 원고가 반복해서 요구한 모티프(멈춘 손, 움켜쥔 손가락)를 쓰므로 대체가 정당하고, 소품 연속성 부담이 없다.

### 치명(KILL) 지적과 처리
| 지적 | 처리 |
|---|---|
| "2명만 등장" 전역 선언 ↔ 회의실 앉은 인물 = 모순 | 공간별로 분해 ("복도엔 두 사람 / 회의실엔 A와 앉은 한 사람") |
| 촬영대본에 없는 샷 4 삽입 | 삭제. 9샷 재매핑 (4+2+3+4+5+3+2+5+2=30) |
| `locked-off` + `push-in` 자기모순 | 푸시인을 유일한 이동으로 재기술 |
| 0.5초 암전은 1초 그리드 아래라 불가 | 화면은 눈빛에서 종료, 암전은 조립 단계로 이관 |
| 유일한 풀백 샷에 @Image 미결속 | 플레이트 결속 추가 |
| CU 샷들에 배경 미기재 → 시트 회색 누출 | 샷마다 배경 명시 |
| 리듬 워드 0개 | 9개 샷 전부 HELD/BRIEF/STANDARD/LONG 부여 |
| 내적 서술("goes wrong inside him") 5곳 | 촬영 가능한 물리 서술로 치환 |
| 컷마다 하나의 행동 원칙 위반 (2초에 6비트 등) | 비트 수 축소 |
| 인접 싱글샷 프레이밍 동일 (웰드 위험) | MCU / 3/4 CU로 분리 |
| 액션 액시스 미선언 | "A는 축 우측, B는 좌측, 카메라가 선을 넘지 않음" |
| 상자 소유권·개수·손 상태 미기재 | "B 소유, 전편 1개, 손에서 떠나지 않음, A는 만지지 않음" |
| 금지문이 하나의 부정 체인 (첫 항목만 결속) | 항목별 독립 문장으로 분리 |

### 감사 결과 도출된 프롬프트 원칙
1. 부정문은 이름을 부르면 그 이름을 끌어온다 → **"부정 + 대체"**로 쓸 것
2. 아이덴티티 시트를 참조하면 그리드·패널·배경이 누출된다 → **크롭 또는 결속 문장** 필요
3. 무음은 프롬프트 부정문으로 잡히지 않는다 → **호출 파라미터**가 유일한 수단
4. 촬영 불가능한 내적 서술은 모델이 임의로 번역한다 → 물리 서술만 쓸 것

## 11. 주의 사항 (미해결 · 불일치)

1. **`STORY_GUIDE.json`의 유닛 구성(12s/9s/12s)과 최종 렌더(30초 단일 패스)가 다르다.** 대본 정본은 설계 기록으로 남아 있고, 실제 렌더는 9블록 단일 프롬프트로 진행됐다.

4. **자막은 없다.** 하단 여백은 브리프대로 확보되어 있으나 자막을 굽지 않았다.
