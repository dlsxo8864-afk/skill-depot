# 라이선스 정리 — llmvid-blender-voxel-whatif

확인한 날: 2026-11-10. 조건은 바뀔 수 있으니 게시·판매 전에 각 출처를 다시 본다.

## 1. 팩에 든 것

| 파일 | 내용 | 출처 |
|---|---|---|
| `SKILL.md`, `LICENSES.md` | 절차와 설명 | 이 팩을 만들면서 직접 썼다 |
| `example/*.py`, `example/timeline.example.json` | 「만약 하루가 25시간이라면」을 만든 스크립트와 타임라인 예제 | 이 프로젝트에서 LLM으로 작성했다. `create_voxel.py`는 Google CLI로 만든 기초 구현을 검토해 고쳐 적용했고(블렌더 5.x 키 보간, 걷기 좌표, 자세 동작 키, 이름 검사 등), 나머지 파일은 마감 코드다 |

- 팩 스크립트에 따로 라이선스를 붙이지 않았다. 받은 사람이 자기 영상을 만드는 데 고쳐 쓰라는 용도다.
- `create_voxel.py`, `preview_checks.py`, `render_final.py`는 블렌더 내부 파이썬 API(`bpy`)를 쓴다. 블렌더 재단은 `bpy`를 쓰는 스크립트를 외부에 공개 배포할 때 GNU GPL 호환 라이선스를 따르라고 안내한다(https://www.blender.org/about/license/ 의 Add-ons 항목). 팩 스크립트를 외부에 다시 배포하려면 이 조건을 확인한다.
- 형식은 인스타그램의 복셀 '만약에' 연작을 보고 정했다. 화면 구성과 연출 방식(블록 인물, 타일 색 세트, 군중, 굵은 흰 자막)만 참고했고, 그 계정의 영상·이미지·음성·캐릭터·제목·대본은 팩에 없다. 예제의 대본과 인물은 새로 만들었다.
- 팩에 포함되지 않은 것: 내레이션 음성, 배경음, 렌더한 프레임과 영상, `.blend` 파일, 외부 3D 에셋, 글꼴 파일.

## 2. 팩이 쓰는 도구

| 도구 | 라이선스 | 결과물에 미치는 영향 |
|---|---|---|
| Blender 5.2.3 LTS (4.5 LTS 미확인) | GNU GPL (v3 이상으로 배포) | 블렌더로 만든 그림·영상·`.blend` 파일은 만든 사람의 것이다(블렌더 라이선스 페이지의 Your Artwork 항목) |
| ffmpeg | 빌드 구성에 따라 LGPL 또는 GPL | 만든 영상의 저작권에는 영향이 없다. ffmpeg 실행 파일을 제품에 넣어 다시 배포할 때만 의무가 생긴다 |
| Python 3.10+ | PSF License | 결과물에 제약 없음 |
| Pillow | MIT-CMU (HPND) | 결과물에 제약 없음(`sheet.py` 검수 시트에만 쓴다) |

H.264(libx264)·AAC로 인코딩한다. 일반적인 영상 게시에는 문제가 되지 않지만, 인코더를 제품에 넣어 파는 경우는 특허 라이선스를 따로 확인한다.

## 3. 외부 소재

외부 소재 없음, 전부 코드로 만든 도형.

- 외부 3D 모델(glTF, FBX, OBJ 등), 외부 텍스처 이미지, HDRI 환경 맵, 외부 일러스트를 쓰지 않는다.
- 공원·방·경기장 세트, 나무·벤치·가구·무대·전광판, 인물의 얼굴 픽셀 그림과 몸, 관중은 모두 블렌더 파이썬 코드로 상자를 배치하고 픽셀 질감을 코드로 칠해 만든다.

## 4. 글꼴

- 팩에는 글꼴 파일이 없다.
- `fontfind.py`가 운영체제에 설치된 글꼴을 Noto Sans KR → 맑은 고딕 순으로 찾는다. 제목 카드와 자막이 같은 글꼴을 쓴다.
- **Noto Sans KR:** SIL Open Font License 1.1.
- **맑은 고딕:** Windows에 딸린 글꼴이다. Windows 글꼴 라이선스를 따른다. 조건이 분명해야 하는 게시·상업용이면 Noto Sans KR을 설치해 쓰거나 `--font`로 권리가 분명한 글꼴을 넘긴다.
- 픽셀 글꼴을 쓰려면 사용자가 라이선스를 확인한 파일을 직접 받아 `--font`로 넘긴다. 팩은 픽셀 글꼴을 고르거나 내려받지 않는다.
- `finish.py`는 찾은 글꼴 파일을 작업 폴더의 `fonts/`로 복사한다. 작업용 사본이니 남에게 따로 나눠 주지 않는다.

## 5. 음성·효과음

- 내레이션 음성과 배경음은 팩에 없다.
- 음성은 사용자가 녹음하거나 TTS(음성 합성) 서비스로 만든다. TTS를 쓰면 그 서비스의 상업적 이용 범위와 출처 표기 의무를 사용자가 확인한다.
- `--music`으로 넣는 배경음도 사용 권리를 사용자가 확인한다.

## 6. 대본

예제의 대본(「만약 하루가 25시간이라면」)과 자막 문구는 동작 시험을 위해 새로 쓴 예시다. 참고한 계정의 대본이 아니다. 실제 영상에는 사용자가 쓴 대본을 넣는다.
