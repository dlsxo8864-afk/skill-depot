# 대본 쓰는 법

## 왜 예전 대본이 심심했나

예전 대체 문구: "오늘의 식사 후보, ○○.", "어떤 모습인지 가까이 볼까요?", "한 상의 구성을 둘러보고,", "눈길이 가는 장면도 남겨요."

- 무엇이 보이는지 말하지 않는다. 어느 식당에나 붙는 말이다.
- 첫 줄이 인사 다음의 소개다. 볼 이유가 없다.
- 15초에 여섯 줄, 줄당 8자 안팎이라 초당 3음절대로 늘어진다. 실제 맛집 쇼츠는 4음절대다.
- 음성 지시가 "담백하게, 과한 감탄 없이"였다.

## 사실과 재미를 함께 지키는 방법

| 쓰고 싶은 말 | 문제 | 이렇게 |
|---|---|---|
| 정말 맛있어요 | 먹지 않았다 | 이 윤기, 그냥 못 지나가죠 |
| 제가 먹어 봤는데요 | 경험 위장 | 딱 봐도 안 심심하게 생겼잖아요 |
| 인생 맛집 | 경험 위장 | 메뉴 이름과 보이는 특징 |
| 국물이 진해요 | 맛 단정 | 국물 색 좀 보세요 |
| 전국 1위 | 근거 없음 | 쓰지 않음 |
| 12,000원 (자료에 없음) | 지어냄 | 쓰지 않음. 자료에 있으면 그대로 |

감각어는 사진에 보일 때만: 윤기, 김, 두께, 색, 자글자글(불판이 보일 때), 바삭(튀김옷이 보일 때), 모락모락(김이 보일 때).

조건이나 단점 한 줄은 광고 느낌을 줄인다(여러 자료 공통). 자료에 있을 때만 쓴다: 브레이크 타임, 주차, 포장 범위.

## 형식 8종

| 형식 | 쓰는 곳 | 필요한 사실 | 흐름 |
|---|---|---|---|
| 친구가 콕 집어 주기 | 기본 | 없음 | 상황 → 보이는 것 → 끌기 → 대표 메뉴 → 꺾기 → 공간·조건 → 상호 |
| 침샘 자극 묘사 | 음식 사진이 좋은 곳 | 없음 | 장면 → 질감 → 소리·온도 → 다른 음식 → 한 상 → 상호 |
| 궁금증 먼저 | 메뉴가 특이한 곳 | 없음 | 질문 → 힌트 → 힌트 → 답 → 굳히기 → 상호 |
| 정보 콕콕 | 메뉴·가격을 확인한 곳 | 메뉴, 가격 또는 위치 | 센 정보 → 메뉴·가격 → 구성 → 위치 → 조건 → 상호 |
| 가기 전 알아 둘 것 | 조건을 확인한 곳 | 영업·주차·포장 | 훅 → 하나 → 둘 → 셋 → 대표 메뉴 → 상호 |
| 이 가격 실화? | 가성비 | 가격 | 가격 → 구성 → 구성 → 반응 → 조건 → 상호 |
| 노포 담담하게 | 오래된 집 | 가게 이력 | 시간 → 흔적 → 사람·도구 → 음식 → 여운 → 상호 |
| 예능처럼 수다 | 양 많은 집, 젊은 손님 | 없음 | 호들갑 → 태클 → 감탄 → 반전 → 참견 → 상호 |

인기 클립 62개 문형(업무/15 카피 패턴 v1.3)에서 골랐다. 반응 낚시형, 웨이팅 인증형, 방문 일기형은 실제 경험이 있어야 하므로 뺐다.

## 말끝과 리듬

- 해요체가 기본이다. 말투에 따라 합쇼체를 섞는다.
- 말끝 표: 보이시죠, 생겼죠 / 거든요 / 잖아요 / 네요 / 까요? / 세요 / 고요 / 는데요 / 명사로 끝맺기.
- 짧은 줄은 친다, 긴 줄은 풀어 준다. 번갈아 쓴다.
- 쉼표로 숨 쉴 곳을 만든다. 말줄임표는 한두 번이다.
- 글말 금지: 및, 또는, 해당, 이를 통해, 본 영상.
- 화면을 읽지 않는다. 화면 글(title)과 말은 다른 표현으로 쓴다.

## 사진과 글 맞추기

사진 번호와 대본을 한 번에 쓰면 어긋난다(실내 사진에 '푸짐한 한 상'). 순서를 나눈다.

1. 사진을 한 장씩 크게 읽는다. 보이는 것, 사진 속 글자, 이 사진으로 할 수 있는 말, 가능한 움직임을 적는다. 같은 사진은 다시 읽지 않는다.
2. 줄마다 사진 → 보이는 것 → 말 → 장면 순서로 쓴다. 말이 먼저 떠올라도 그 사진에 없으면 버린다.
3. 제목은 그 사진에 보이는 것이다. 글이 특정 음식·양·색·공간을 가리키면 그 사진에 보여야 한다. 가격은 그 메뉴나 메뉴판 사진에, 시간·주차는 입구나 실내 사진에 붙인다. 말 걸기와 저장 권유는 사진을 가리키지 않으므로 제목만 본다.
4. 다 쓴 뒤 사진 앞에 '컷 N 사진' 번호를 붙여 실제 사진과 대조하고, 어긋난 컷만 고친다. 사진을 옮기면 제목과 움직임은 그 사진의 메모로 바꾼다.
5. 사람이 쓴 글은 그대로 두고 사진과 제목을 고른다. 사람이 다시 쓰라고 할 때만 글을 쓴다.

## 읽기 변환(say)

자막은 숫자를 유지하고 소리만 한글로 푼다.

| 자막 | 읽는 글 | 규칙 |
|---|---|---|
| 12,000원 | 만 이천 원 | 금액은 한자어, 만 앞의 일은 읽지 않음 |
| 3시 30분 | 세 시 삼십 분 | 시는 고유어, 분은 한자어 |
| 2인분 | 이 인분 | 인분은 한자어 |
| 3그릇, 2개, 4명 | 세 그릇, 두 개, 네 명 | 세는 말은 고유어 |
| 3번 출구 / 3번 구워요 | 삼 번 출구 / 세 번 구워요 | 번호는 한자어, 횟수는 고유어 |
| 6월, 10월 | 유월, 시월 | 예외 |
| BBQ, 1+1 | 비비큐, 원 플러스 원 | 굳어진 읽기 |
