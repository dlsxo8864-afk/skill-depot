# 픽셀 애니메이션 영상 (llmvid-pixel-story)

검증된 예제 하나와 그것을 새 대본에 맞게 고치는 절차다. 버튼 하나로 끝나는 자동 도구가 아니다. 예제를 먼저 돌려 본 뒤, 장면 함수를 대본에 맞게 다시 쓴다.

## 1. 만드는 것

- 세로 1080x1920, 24fps MP4. 내부 해상도 180x320을 6배로 키운 16색(sweetie16) 픽셀 화면.
- 모든 프레임은 시간의 함수다. 장면마다 `def 장면(c, x)` 하나가 `x.t`(장면 안 시간)·`x.T`(전체 시간)를 받아 캔버스 `c`에 그린다.
- 한글 자막은 픽셀 글꼴(Galmuri11)로 영상 안에 직접 그린다. 배경 음악(칩튠)과 효과음도 코드로 합성한다.
- 예제(`example/film.py` + `example/script.json`)는 공통 예제 대본 「점심 메뉴 정하는 법」 15초다. 같은 묶음의 다른 팩도 모두 이 대본을 쓰고, 팩마다 화풍과 연출만 다르다. 장면 5개: 묻기(단톡 입력), 대답(단톡), 기다림(시계·배고픔 눈금), 결정(알림·팀장), 결말(결과 종이·도장).

## 2. 입력

| 입력 | 필수 | 설명 |
|---|---|---|
| 대본 | 필수 | 20~60초 분량. 줄마다 무슨 그림이 나올지 떠올릴 수 있어야 한다. |
| 음성 파일(wav/mp3) | 선택 | 없으면 음악만 넣고, 장면 길이는 대본 낭독 속도(1초에 5~6자)로 잡는다. |
| 자막 타이밍 | 선택 | 없으면 음성에서 구간을 잡거나(무음 구간 기준) 사용자에게 받는다. |
| 저장 폴더 | 필수 | 중간 파일과 완성 MP4를 둘 곳. |

## 3. 환경 확인

작업 전에 아래를 확인한다. 없으면 설치하지 말고 사용자에게 먼저 묻는다.

```
python -c "import PIL, numpy, imageio_ffmpeg; print(PIL.__version__, numpy.__version__, imageio_ffmpeg.__version__)"
ffmpeg -version
```

- 필요한 것: Python 3.10 이상, Pillow, numpy, imageio-ffmpeg. ffmpeg은 PATH에 없어도 imageio-ffmpeg에 든 것으로 대신한다.
- 검증한 조합: Python 3 + Pillow 13.0 + numpy 2.4 + imageio-ffmpeg 0.6, Windows 10.
- Windows에서는 `python -X utf8`로 실행한다(한글 출력 깨짐 방지).

## 4. 절차

1. **예제를 그대로 돌린다.** 환경이 되는지 먼저 본다.
   ```
   python -X utf8 example/film.py sheet --out <작업폴더>
   ```
   `tests_sheet1.png`, `tests_sheet2.png`(구간마다 정지 화면 세 장)가 나온다. 직접 열어 본다.
2. **대본을 장면으로 나눈다.** 장면 하나는 2~5초, 한 장면에 한 가지 사건. 장면 이름·길이·그릴 것·자막을 표로 먼저 적는다. 길이의 합이 음성 길이와 같아야 한다.
3. **`example/`의 `film.py`, `script.json`, `pixelvid.py`, `fonts/`를 작업 폴더로 복사한다.** 대본은 `script.json`에 쓰고, 장면 함수는 `film.py`에서 고친다(5절).
4. **시트를 뽑아 본다**(6절). 고치고 다시 뽑기를 되풀이한다.
5. **렌더한다.**
   ```
   python -X utf8 film.py render --out <작업폴더>
   ```
   `video_silent.mp4`(무음)와 `music.wav`가 나온다. 15초 영상에 16초쯤 걸린다.
6. **소리를 입힌다.**
   ```
   python -X utf8 example/finish.py --dir <작업폴더> --out <완성.mp4> --audio <음성.wav>
   ```
   음성이 없으면 `--audio`를 뺀다(음악만 들어간다). 음악 크기는 `--music-vol`로 조절한다.
7. **결과를 확인한다.** `ffprobe`로 길이·해상도·오디오 스트림을 보고, 완성본에서 정지 화면 몇 장을 뽑아 자막과 그림이 맞는지 본다.

## 5. 대본에 맞춰 고칠 곳

대본과 그리는 방법을 나눠 두었다. `film.py` 안에는 대사도 시각도 없다.

- **`script.json`(대본)**: 길이, 등장인물(`cast`), 단톡방 이름, 구간(`beats`)마다 시작·끝 초, 키워드, 대화(`chat`: 초, 누구, 문구), 시계(`clock`), 눈금(`gauge`), 도장(`stamp`), 결과(`result`), 자막(`subs`), 효과음 시각(`sfx`). 새 대본이면 이 파일을 새로 쓴다.
- **`film.py`의 장면 함수**: `@mv.scene(DUR["구간 id"], "구간 id")`가 붙은 함수 하나가 구간 하나를 그린다. 문구와 시각은 `script.json`에서 읽은 값(`CHAT`, `B`, `STAMP`, `RESULT` …)을 쓴다. 구간 id나 보여 줄 것이 달라지면 장면 함수를 새로 쓴다. 예제의 다섯 함수는 본보기다.
- **자막**: `script.json`의 `subs`. `(시작 초, 끝 초, 문구)`, 줄바꿈은 `\\N`, 한 줄 12자 안팎, 최대 2줄.
- **음악과 효과음**: `Song(bpm=...)`, `song.track(...)`. 효과음은 `sfx`의 초(전송·알림·도장)와 대답이 오는 초에 자동으로 붙는다.
- **시트 시각**: 구간마다 세 장(30%, 60%, 93% 지점)을 자동으로 고른다.

다시 쓸 수 있는 부품(예제 안, 그대로 써도 된다):

- `kt(c, 글, x, y, 색, align, outline, bold)`: 한글 픽셀 글자.
- `bust(c, cx, by, who, expr, T)`: 상반신 인물(눈 깜빡임·표정).
- `room(c, t, upto, x)`: 대본의 대화를 그대로 그리는 단톡 화면(내 메시지는 보내기 전에 입력창에 쳐진다). `chip(c, 글, cx, y)`: 키워드 칩.
- `office(c, T, dark)`: 사무실 배경. `phone(...)`, `chat(...)`, `input_bar(...)`: 휴대폰 채팅 화면. `type_slice(...)`: 타이핑 효과.
- 엔진 함수(이징, 입자, 날씨, 팔레트 등)는 `references/upstream/api.md`에 있다. 연출 요령은 `craft.md`, 이야기 구성은 `story.md`.

새 인물·소품·배경이 필요하면 `c.rect`, `c.px` 같은 기본 도형으로 직접 그린다. 팔레트 16색 밖의 색은 쓰지 않는다(`strict_palette=True`).

## 6. 중간 검수

최종 렌더 전에 반드시 시트를 뽑아 직접 본다. 확인할 것:

- 자막이 화면 밖으로 나가거나 인물·말풍선과 겹치지 않는가.
- 한글이 깨지지 않았는가(네모로 나오면 글꼴 경로 문제).
- 장면이 바뀌는 시각이 음성의 문장 경계와 맞는가.
- 정지 화면만 봐도 무슨 장면인지 알 수 있는가. 모르겠으면 그림을 더 단순하고 크게 그린다.
- 움직임은 시트로 안 보인다. 의심되는 구간은 `mv.render(경로, start=초, end=초)`로 2~3초만 뽑아 본다.

## 7. 함정

- `film.py`와 `pixelvid.py`, `fonts/` 폴더는 같은 위치에 있어야 한다. 복사할 때 셋을 함께 옮긴다.
- 글꼴 크기는 12로 고정한다. Galmuri11은 이 크기에서만 픽셀이 또렷하다.
- 내부 해상도가 180x320이라 한 줄에 한글 13자 정도만 들어간다. 긴 문장은 줄을 나눈다.
- 장면 길이의 합이 음성보다 짧으면 `finish.py`가 영상 길이에서 소리를 자른다. 길이를 먼저 맞춘다.
- 사람 얼굴 연기나 전신 동작은 이 방식으로 설득력 있게 만들기 어렵다. 상반신·소품·화면 연출로 푼다.
- 효과음 `at` 값은 전체 시간 기준이다(장면 안 시간이 아니다).

## 8. 실측 시간

- 15초 예제 기준(Windows 10 데스크톱, 실측): 시트 2장 2초, 렌더 16초(360프레임), 소리 입히기 2초 안쪽.
- 새 대본으로 장면을 다시 쓰는 데 드는 시간(LLM 작업)은 장면 수와 검수 횟수에 달렸다. 예제는 시트 검수를 서너 번 거쳤다.

## 9. 완료 기준

- 완성 MP4가 1080x1920, 24fps, 음성 길이와 같은 길이(±0.1초)다.
- 오디오 스트림이 있고 음성이 음악에 묻히지 않는다.
- 시트 검수에서 자막 겹침·글자 깨짐이 0건이다.
- 사용자에게 결과 경로, 길이, 걸린 시간, 남은 문제를 알렸다.

## 10. 라이선스

`LICENSES.md`를 본다. 엔진 `pixelvid.py`는 MIT, 글꼴 Galmuri11은 SIL OFL 1.1이다. 둘 다 상업 이용이 가능하고, 재배포할 때 라이선스 문서를 함께 둔다.

## 11. 쓰지 않는 것

- 영상 생성 AI, 이미지 생성 AI, 유료 API.
- 인터넷에서 내려받는 소재. 필요한 것은 모두 이 폴더에 있다.
- 16색 팔레트 밖의 색, 픽셀 글꼴이 아닌 글꼴.
